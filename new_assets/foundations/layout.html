Density

This product is table-first, so the row is the unit of density: 44px tall, 16px horizontal padding, a 34px sticky header above it. Controls are 32px. A screen should show around twenty employees without scrolling on a laptop.

The frame

Every org-scoped screen is the same frame: a 236px sidebar, a sticky 52px topbar, and a single 24px-padded content well. Page content is left-aligned and full-width up to 1440px; forms cap at 560px and documents at 720px so lines stay readable.

Rules

Do use flex or grid with gap for every group. Do let tables run full width and scroll horizontally with the first column pinned.
Don't centre app content. Don't nest cards. Don't put two competing primary actions in one header.
